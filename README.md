# Desktop Sticky Notes 📝

Легковесное WPF приложение для создания виртуальных стикеров на рабочем столе Windows.

![.NET](https://img.shields.io/badge/.NET-9.0-blue)
![Platform](https://img.shields.io/badge/platform-Windows-lightgrey)
![License](https://img.shields.io/badge/license-MIT-green)

## ✨ Возможности

- 📌 **Виртуальные стикеры** - создавайте неограниченное количество заметок
- 🖱️ **Контекстное меню** - правый клик по рабочему столу → "Создать заметку"
- 💾 **Автосохранение** - текст сохраняется автоматически через 500мс после печати
- 📍 **Запоминание позиции** - каждая заметка появляется там, где вы её оставили
- 🔒 **Закрепление** - возможность зафиксировать заметку (запрет перемещения/изменения размера)
- 📚 **История** - удалённые заметки архивируются, можно восстановить
- 🚀 **Автозапуск** - приложение запускается вместе с Windows
- 🎨 **Минималистичный дизайн** - имитация бумажного стикера

## 🚀 Использование

### Создание заметки
- **Способ 1**: Правый клик по пустому месту на рабочем столе → "Создать заметку"
- **Способ 2**: Запустите приложение напрямую

### Управление заметками
- **Перемещение**: Зажмите левую кнопку мыши на заметке и перетащите
- **Изменение размера**: Потяните за правый нижний угол
- **Закрепить**: Правый клик → "Закрепить" (заметка станет неподвижной)
- **История**: Правый клик → "История" (управление архивом)
- **Удалить**: Правый клик → "Удалить заметку" (заметка переместится в архив)

### Горячие клавиши
- `Ctrl+Z` / `Ctrl+Y` - отмена/повтор (стандартные для TextBox)
- `Ctrl+C` / `Ctrl+V` - копировать/вставить
- `Ctrl+X` - вырезать

## 🛠️ Технологии

- **Framework**: .NET 9.0
- **UI**: WPF (Windows Presentation Foundation)
- **Язык**: C# 12
- **Хранилище данных**: 
  - Текст заметок: `%AppData%\DesktopStickyNote\note_*.txt`
  - Позиции окон: `%AppData%\DesktopStickyNote\positions.json`
  - Архив: `%AppData%\DesktopStickyNote\History\`
